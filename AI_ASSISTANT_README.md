# AI Ассистент - Документация

## Обзор

AI Ассистент - это интеллектуальный инструмент для работы с заметками, интегрированный в браузерный блокнот. Он позволяет анализировать, суммаризировать и взаимодействовать с вашими заметками с помощью искусственного интеллекта.

## Новая функциональность выбора заметок

### Что изменилось

Реализована новая система выбора заметок для суммаризации:
- Вместо автоматической суммаризации текущей заметки теперь можно выбрать любые заметки
- Добавлен интерфейс выбора с возможностью множественного выбора
- Реализована функция поиска по заметкам
- Добавлены кнопки "Выбрать все" и "Очистить выбор"

### Как использовать

1. Откройте AI Ассистент, нажав на иконку 🤖 в правом меню
2. Нажмите кнопку "Выбрать заметки для суммаризации"
3. В открывшемся модальном окне:
   - Используйте поиск для быстрого нахождения нужных заметок
   - Отмечайте галочками заметки, которые хотите суммаризировать
   - Используйте кнопку "Выбрать все" для выбора всех видимых заметок
   - Используйте кнопку "Очистить" для сброса выбора
4. Нажмите "Подытожить выбранные" для запуска процесса суммаризации

## Архитектура системы

### Фронтенд (JavaScript)

Файл: `assets/ai-chat.js`

#### Основные функции:

- `initAIChat()` - Инициализация всех обработчиков событий
- `openNotesSelection()` - Открытие модального окна выбора заметок
- `loadNotesList()` - Загрузка и отображение списка заметок
- `updateNoteSelection()` - Обновление состояния выбора заметок
- `updateSelectionUI()` - Обновление пользовательского интерфейса выбора
- `filterNotes()` - Поиск и фильтрация заметок
- `selectAllNotes()` - Выбор/снятие выбора всех заметок
- `clearSelection()` - Очистка выбора
- `summarizeSelectedNotes()` - Отправка выбранных заметок на суммаризацию

#### Локальное хранилище:

- `selectedNotes` - Массив ID выбранных заметок в localStorage

### Бэкенд (Go)

Файл: `serv/ai_handler.go`

#### Структуры данных:

```go
type SummarizeSelectedRequest struct {
    User_id  string   `json:"User_id"`
    Note_ids []string `json:"Note_ids"`
}
```

#### Основные функции:

- `AISummarizeSelectedHandler()` - Обработчик HTTP запросов для суммаризации
  - Проверяет существование и доступ к каждой заметке
  - Собирает содержимое выбранных заметок
  - Отправляет данные в AI сервис
  - Возвращает суммаризированный результат

### Шаблон (HTML/CSS)

Файл: `templates/new_page.html`

#### Новые элементы:

- Модальное окно выбора заметок (`#notes-selection-modal`)
- Поисковая строка с иконкой
- Список заметок с чекбоксами
- Панель управления выбором (количество выбранных, кнопки действий)

#### CSS классы:

- `.notes-selection-content` - Основной контейнер модального окна
- `.note-item-select` - Элемент списка заметок
- `.note-checkbox` - Чекбоксы для выбора
- `.search-box` - Поисковая строка
- `.selection-footer` - Нижняя панель с кнопками

## API Endpoints

### `/api/ai/summarize-selected` (POST)

**Запрос:**
```json
{
    "User_id": "user123",
    "Note_ids": ["note1", "note2", "note3"]
}
```

**Ответ (успех):**
```json
{
    "status": true,
    "reply": "Суммаризированное содержание заметок..."
}
```

**Ответ (ошибка):**
```json
{
    "status": false,
    "message": "Описание ошибки"
}
```

## Безопасность

- Все запросы проверяют принадлежность заметок пользователю
- Проверяется существование каждой заметки перед обработкой
- Защита от SQL-инъекций через использование параметризованных запросов

## Производительность

- Параллельная обработка нескольких заметок
- Эффективная фильтрация и поиск на фронтенде
- Минимальное количество запросов к базе данных

## Требования

- Go 1.19+
- PostgreSQL база данных
- Groq API ключ (устанавливается в .env файле)
- Современный браузер с поддержкой ES6

## Настройка

1. Установите Groq API ключ в `.env` файл:
   ```
   GROQ_API_KEY=your_api_key_here
   ```

2. Убедитесь, что база данных настроена и запущена

3. Запустите сервер:
   ```bash
   go run main.go
   ```

## Использование AI

### Возможности:

1. **Суммаризация заметок** - Создание краткого содержания выбранных заметок
2. **Ответы на вопросы** - Интерактивный чат для помощи с заметками
3. **Организация информации** - Помощь в структурировании знаний

### Рекомендации по использованию:

- Выбирайте заметки с похожей тематикой для лучшей суммаризации
- Используйте поиск для быстрого нахождения нужных заметок
- Не выбирайте слишком много заметок одновременно (рекомендуется до 10)
- Для лучшего результата используйте заметки с достаточным объемом текста

## Поддержка

При возникновении проблем:
1. Проверьте консоль браузера на наличие ошибок
2. Убедитесь, что API ключ Groq установлен правильно
3. Проверьте подключение к базе данных
4. Убедитесь, что выбраны заметки перед суммаризацией
