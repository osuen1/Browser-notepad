# Блокнот для веб-браузера

Этот проект представляет собой простое веб-приложение-блокнот, позволяющее пользователям создавать, просматривать и управлять своими заметками через веб-браузер. Оно имеет клиент-серверную архитектуру с аутентификацией пользователя и постоянным хранением данных.

## Возможности

*   **Управление заметками:** Создавайте новые заметки с датами и просматривайте список всех сохраненных заметок.
*   **Аутентификация пользователя:** Безопасная функция регистрации и входа в систему с использованием сессий.
*   **Восстановление пароля:** Возможность сброса забытых паролей по электронной почте.
*   **Постоянное хранение:** Заметки и данные пользователя хранятся в базе данных PostgreSQL.
*   **RESTful API:** Чистый API для клиент-серверного взаимодействия.

## Используемые технологии

*   **Бэкенд:**
    *   **Go:** Основной язык для серверной логики.
    *   `net/http`: Для обработки HTTP-запросов и маршрутизации.
    *   `html/template`: Для серверного рендеринга HTML-страниц.
    *   `github.com/gorilla/sessions`: Для управления пользовательскими сессиями и аутентификацией.
    *   `github.com/jackc/pgx/v5/pgxpool`: Драйвер PostgreSQL для взаимодействия с базой данных.
    *   `github.com/joho/godotenv`: Для загрузки переменных окружения.
    *   `server/mail`: Внутренний пакет для работы с электронной почтой (например, для восстановления пароля).
*   **Фронтенд:**
    *   **HTML, CSS, JavaScript:** Стандартные веб-технологии для пользовательского интерфейса и клиентской логики.
*   **База данных:**
    *   **PostgreSQL:** Реляционная база данных для хранения учетных записей пользователей и заметок.

## Архитектура и принцип работы

Приложение следует клиент-серверной модели. Фронтенд, построенный с использованием HTML, CSS и JavaScript, взаимодействует с бэкенд-сервером на Go, который обрабатывает бизнес-логику, сохранение данных и аутентификацию.

### Взаимодействие клиента и сервера

1.  **Главная страница (создание заметки):**
    *   Пользователь переходит на главную страницу, которая отображается сервером Go.
    *   Пользователи могут вводить текст в специальное поле.
    *   После нажатия кнопки «Сохранить» или аналогичной кнопки клиент отправляет POST-запрос на сервер. Этот запрос содержит данные JSON, включая текст заметки, текущую дату и идентификатор пользователя.
    *   Конечная точка `/api/notes/create` сервера Go (обрабатываемая функцией `Create_note_handler`) принимает этот запрос. Она декодирует JSON и сохраняет данные заметки в базе данных PostgreSQL.

2.  **Страница списка заметок:**
    *   Когда пользователь заходит на страницу списка заметок, клиент отправляет GET-запрос на сервер, чтобы получить все заметки, связанные с вошедшим в систему пользователем.
    *   Конечная точка `/api/notes` сервера (обрабатываемая функцией `Get_notes_handler`) запрашивает заметки пользователя из базы данных PostgreSQL.
    *   Затем сервер отправляет POST-ответ обратно клиенту, содержащий полученные заметки в формате JSON.
    *   Клиент декодирует этот JSON и динамически вставляет заметки в неупорядоченный список (`<ul>`) для отображения.
    *   Также существует конечная точка `/api/notes/delete` для удаления заметок из базы данных.

### Процесс аутентификации

*   **Регистрация:** Пользователи могут создавать новые учетные записи, предоставляя имя пользователя, адрес электронной почты и пароль. Сервер хеширует пароль и сохраняет учетные данные пользователя в базе данных.
*   **Вход:** Пользователи входят в систему со своими учетными данными. При успешной аутентификации устанавливается сессия с использованием файлов cookie, и идентификатор пользователя сохраняется в сессии. Также отправляется уведомление по электронной почте о входе в систему.
*   **Восстановление пароля:** Если пользователь забыл свой пароль, он может инициировать процесс восстановления. На зарегистрированный адрес электронной почты отправляется электронное письмо с уникальным токеном, позволяющим сбросить пароль на специальной странице.

## Установка и настройка

Чтобы запустить этот проект на вашей локальной машине, выполните следующие шаги:

### Необходимые условия

*   Go (рекомендуется версия 1.18 или выше)
*   Сервер базы данных PostgreSQL

### Шаги

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/your-username/Browser-notepad.git
    cd Browser-notepad
    ```
    (Замените `https://github.com/your-username/Browser-notepad.git` на фактический URL-адрес репозитория.)

2.  **Настройте PostgreSQL:**
    *   Создайте новую базу данных PostgreSQL (например, `notepad_db`).
    *   Создайте пользователя PostgreSQL с соответствующими разрешениями для этой базы данных.
    *   Убедитесь, что ваша схема базы данных настроена. Возможно, вам потребуется заглянуть в каталог `Browser-notepad/sql` для файлов определения схемы или связаться с владельцем проекта для получения инструкций по настройке.

3.  **Создайте файл `.env`:**
    Создайте файл переменной окружения с помощью команды `go run ./conf/generate_env.go`. В нем, в строке `DATABASE_URL` укажите ваш логин, пароль и имя базы данных вместо дефолтных username, password и dbname. Больше никак не модифицируйте эту строку, иначе приложение не сможет подключиться к базе данных.
    
    Так же можете создать свой временный пароль для работы с почтой. Однако тогда придется раскомментировать следующие строки в функции `LoginHandler` в файле `serv/page_handler.go`:
    
    ```go
		mailer := mail.New_Dialer()
				if err := mailer.Send_enter_mail(user_email); err != nil {
					http.Error(w, "An error with send email", http.StatusInternalServerError)
					fmt.Print(err)
				}
	```
    *   `PORT`: Порт, на котором будет прослушивать сервер Go. По умолчанию 3030.
    *   `COOKIE_KEY`: Секретный ключ, используемый `gorilla/sessions` для шифрования данных сессии. Это должна быть длинная случайная строка (например, 32 символа).
    *   `DATABASE_URL`: Ваша строка подключения к PostgreSQL.
    *   `MAIL_KEY`: Ваш временный пароль для работы с почтой.

4.  **Установите зависимости Go:**
    Перейдите в каталог `Browser-notepad` и установите необходимые модули Go:
    ```bash
    go mod tidy
    ```

5.  **Запустите сервер:**
    Из каталога `Browser-notepad` запустите приложение Go:
    ```bash
    go run main.go
    ```
    Вы должны увидеть сообщение о том, что сервер запущен, обычно на `http://localhost:3030` (или на порту, указанном вами в `.env`).

6.  **Доступ в браузере:**
    Откройте веб-браузер и перейдите по адресу `http://localhost:3030` (или настроенному порту), чтобы получить доступ к приложению блокнота.
